# ── Rendering backend ────────────────────────────────────────────────────────
#
# pywebview needs a platform webview. It picks one automatically:
#
#   Windows  →  WebView2 / WinForms. pythonnet is pulled in automatically by
#               pywebview on win32. Nothing else to install.
#
#   macOS    →  Cocoa / WebKit via pyobjc, also pulled in automatically.
#
#   Linux    →  GTK/WebKit2 first, Qt only as a fallback. The GTK bindings are
#               system packages, not pip packages. On Debian/Ubuntu:
#
#                   sudo apt install python3-gi python3-gi-cairo \
#                                    gir1.2-girepository-2.0 gir1.2-webkit2-4.1
#
#               On Fedora:
#
#                   sudo dnf install python3-gobject webkit2gtk4.1
#
# If you would rather use the Qt backend on Linux — for example on a system
# without the GTK packages — install it explicitly:
#
#     pip install 'pywebview[qt]'
#
# Note that this pulls in PyQt6, which is GPLv3-or-commercial. That is your
# choice to make as a user; ARIA does not ship it as a default dependency.
