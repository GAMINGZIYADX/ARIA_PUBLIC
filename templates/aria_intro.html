Capabilities

What to try first

Type or say any of these to get started. ARIA understands natural language — no exact phrasing required.

Voice Input
Hold Space to speak, or click the mic button. Say "Aria" to activate hands-free via wake word.
OpenWakeWord · Whisper
Persistent Memory
Tell ARIA your name, preferences, or any fact. It remembers across sessions and builds a model of how you work.
ChromaDB · JSON
System Controls
Open apps, run bash commands, browse URLs, and control your desktop. Try "open Spotify" or "run diagnostics".
Subprocess · dbus
Spotify
Say "play something chill" or "skip this track". Full playback control via the sidebar or voice.
Spotipy · MPRIS
Camera Vision
Click the camera icon and ask ARIA what it sees. Uses a local vision model — your frames never leave the machine.
Qwen2.5-VL · ONNX
Web Search
Ask any question or say "search for…". ARIA queries DuckDuckGo and summarises results without an API key.
DuckDuckGo · RSS
