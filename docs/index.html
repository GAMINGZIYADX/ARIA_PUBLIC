ARIA
Fully local · offline-first

Your AI. Your Machine.
No Cloud Required.

ARIA is a fully local voice assistant powered by Ollama. Wake word detection, persistent memory, system controls, Spotify — all running on your hardware. Your voice never leaves your machine.

Capabilities

Everything runs locally

No subscriptions. No API rate limits. No data leaving your machine. ARIA handles voice, memory, and system control entirely on your hardware.

Wake Word Detection
Say "Aria" to activate. OpenWakeWord runs fully offline — no continuous cloud streaming, no latency, no privacy concerns.
OpenWakeWord
Persistent Memory
ARIA remembers facts, tracks your habits, learns your music taste, and builds a user model over time — stored locally in a ChromaDB vector database.
ChromaDB · JSON
System Controls
Open apps, execute bash commands, browse URLs, and control your desktop through natural voice commands or the built-in terminal panel.
Subprocess · dbus
Spotify Integration
Search and play tracks, skip songs, pause, and query what's currently playing — via the Spotify Web API with OAuth token caching.
Spotipy · MPRIS dbus
Holographic Web UI
A dark, glassmorphic dashboard with a chat panel, bash terminal, camera feed, settings, and a live world-intelligence feed. Runs in browser or as a desktop window.
Flask · PyWebView
Live Web Intelligence
Real-time RSS polling across F1, AI/tech, geopolitics, and world news. Breaking alerts fire proactively. Web search via DuckDuckGo requires no API key.
RSS · DuckDuckGo
Installation

Up and running in minutes

ARIA needs Python 3.10+, Ollama, and a mic. The interactive setup wizard handles the rest.

01
Clone & install dependencies
Python 3.10+ required. A CUDA-capable GPU is recommended for real-time transcription, but CPU works too.
git clone https://github.com/YOUR_USERNAME/ARIA cd ARIA bash setup.sh
02
Pull an Ollama model
ARIA is tested with Qwen 2.5 but works with any chat model installed in Ollama.
# Install Ollama first: https://ollama.com ollama pull qwen2.5:14b
03
Run the configuration wizard
Detects your installed models automatically. Asks for your name, password, and optional Spotify credentials. Writes .env for you.
python3 setup.py
04
Launch ARIA
Choose your preferred mode. The desktop launcher wraps the web UI in a native window with a custom WM class.
# Web UI in browser bash run-web.sh # Native desktop window python3 launch.py # Voice-only terminal python3 aria.py
