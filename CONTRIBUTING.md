## What's welcome
- Bug fixes and stability improvements
- STT / TTS engine improvements
- New tool integrations (apps, browser, terminal, automation)
- Performance optimizations for local inference
- Documentation improvements and translations

## What's not welcome
- Any modification intended for surveillance or tracking individuals without consent
- Using ARIA as a base for malicious automation, spyware, or keyloggers
- Removing or bypassing the offline-first principle (no forced cloud dependency)
- Misrepresenting ARIA as a different product or hiding its origin
- Commercial use without prior written permission from Ziyad Noucair

---

## How to contribute
1. Fork the repository
2. Create a branch (`feature/your-feature-name` or `fix/issue-description`)
3. Make your changes — keep them focused and well documented
4. Open a pull request with a clear description of what you changed and why

## Setup for contributors
- Python 3.10+
- CUDA-compatible GPU recommended (tested on RTX series)
- Copy `.env.example` to `.env` and fill in your values
- Install dependencies: `pip install -r requirements.txt`
